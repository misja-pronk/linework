# Shop (sample repository)

A made-up web shop, as a code repository holds it: a Compose file for local development, a Helm chart and
a manifest for Kubernetes, Bicep for Azure, an OpenAPI and two AsyncAPI files, and GitHub Actions
workflows. `carto import examples/repo/shop` draws a diagram of each into `diagrams/`; see
[docs/repo-import.md](../../../docs/repo-import.md).
