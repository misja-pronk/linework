Groups and elements
- API clients (Users)
- ml-prod (Cluster)
  - system pool (Node pool)
    - public (Gateway · api.acme.ai)
    - router (Deployment · ×3)

  - gpu pool (L4) (Node pool)
    - llm (Service · :8080)

    - llm (Deployment · vLLM)
    - embed (Deployment · ×2)

Connections
- API clients send traffic to public over HTTPS.
- public sends traffic to router (/v1).
- router sends traffic to rate-limits, sends traffic to llm (Service) (chat) and sends traffic to embed (Service) (embeddings).
- llm (Service) sends traffic to llm (Deployment).
- embed (Service) sends traffic to embed (Deployment).
- llm (Deployment) mounts model-cache · 200Gi, mounts hf-token, is scaled by HPA ×1–8 and connects to from-router-only (Network policy).
- embed (Deployment) mounts model-cache · 200Gi and connects to from-router-only (Network policy).
