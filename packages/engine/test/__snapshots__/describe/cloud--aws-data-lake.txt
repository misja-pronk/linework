Data lake on AWS

AWS and Google Cloud diagram: From sources to dashboards, lakehouse on S3. 14 elements in 5 groups, with 14 connections.

Groups and elements
- Sources
  - ERP (SAP)
  - Orders database (RDS database)
  - Web and app events (Client app)
- data-prod (210987654321 · eu-west-1)
  - Ingest
    - Change data capture (Database Migration Service)
    - Clickstream (Kinesis Data Streams)
    - Delivery (Data Firehose)
  - Lake
    - Raw zone (S3 bucket)
    - ETL jobs (Glue)
    - Curated zone (S3 · Iceberg tables)
    - Catalog and grants (Lake Formation)
  - Serve
    - Ad-hoc SQL (Athena)
    - Warehouse (Redshift)
    - Churn model (SageMaker)
    - Dashboards (QuickSight)

Connections
- ERP sends data to Change data capture.
- Change data capture sends data to Raw zone.
- Raw zone sends data to ETL jobs.
- ETL jobs sends data to Curated zone and is linked with Catalog and grants.
- Curated zone sends data to Ad-hoc SQL, sends data to Warehouse and sends data to Churn model.
- Ad-hoc SQL sends data to Dashboards.
- Warehouse sends data to Dashboards.
- Orders database sends data to Change data capture.
- Web and app events sends data to Clickstream.
- Clickstream sends data to Delivery.
- Delivery sends data to Raw zone.

Key
- Solid line: Connection
- Solid violet line with ticks: Data flow
