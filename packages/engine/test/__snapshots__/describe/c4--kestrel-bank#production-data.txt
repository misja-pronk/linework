Kestrel Online — production, data and events

C4 model: The customer store, Kafka and the notifier in eu-west-1. 4 elements in 6 groups, with 3 connections.

Groups and elements
- Amazon Web Services (Deployment Node: eu-west-1)
  - EKS cluster (Deployment Node: Kubernetes 1.31)
    - banking-api ([Deployment Node: Docker] ×4)
      - Banking API (Container: Spring Boot): Sign-in, accounts and payments as JSON
    - notifier ([Deployment Node: Docker] ×2)
      - Notifier (Container: Go): Turns account events into emails and push messages
  - Amazon RDS (Deployment Node: PostgreSQL 16)
    - Customer store (Container: PostgreSQL 16): Logins, devices and sessions
  - Amazon MSK (Deployment Node: Kafka 3.7)
    - Account events (Container: Kafka): Payments and sign-ins as they happen

Connections
- Banking API connects to Customer store (Reads logins [JDBC]) and sends messages to Account events (Publishes [Kafka]).
- Account events sends messages to Notifier (Delivers).
