Kestrel Online — production, data

C4 model: The customer store in eu-west-1 and the ledger in the Amsterdam data centre. 3 elements in 5 groups, with 2 connections.

Groups and elements
- Amazon Web Services (Deployment Node: eu-west-1)
  - EKS cluster (Deployment Node: Kubernetes 1.31)
    - banking-api ([Deployment Node: Docker] ×4)
      - Banking API (Container: Spring Boot): Sign-in, accounts and payments as JSON
  - Amazon RDS (Deployment Node: PostgreSQL 16)
    - Customer store (Container: PostgreSQL 16): Logins, devices and sessions
- Kestrel data centre (Deployment Node: z/OS mainframe)
  - Core ledger (Software System): Holds every account and booking

Connections
- Banking API connects to Customer store (Reads logins [JDBC]) and connects to Core ledger (Reads and books [ISO 20022 over MQ]).

Key
- Blue icon: Software system
- Sky icon: Container
- Violet icon: Database
- Solid line: Relationship
