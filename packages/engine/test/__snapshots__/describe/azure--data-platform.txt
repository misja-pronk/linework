Data platform

Azure infrastructure diagram: Northwind data · from sources to reports through a bronze, silver and gold lake. 11 elements in 8 groups, with 10 connections.

Groups and elements
- Sources (Upstream)
  - ERP (SQL Server · nightly)
  - CRM (REST API · hourly)
  - Web shop (Clickstream events)
- sub-data-prod (Landing zone · Corp)
  - rg-data-ingest (Resource group)
    - adf-data-prod (Managed VNet · SHIR)
    - evhns-data-prod (Event hub clickstream)
  - rg-data-lake (Resource group)
    - stdatalakeprod (ADLS Gen2 · private)
      - bronze (Raw)
      - silver (Cleaned)
      - gold (Business-ready)
  - rg-data-process (Resource group)
    - dbw-data-prod (Unity Catalog · VNet-injected)
- Databricks serverless (Run by Databricks)
  - Serverless SQL warehouse (Databricks SQL)
- Microsoft Fabric (SaaS)
  - Power BI (Reports · capacity F64)

Connections
- ERP sends data to adf-data-prod.
- adf-data-prod sends data to bronze.
- bronze sends data to silver (clean).
- silver sends data to gold (model).
- gold sends data to Serverless SQL warehouse.
- Serverless SQL warehouse sends data to Power BI (DirectQuery).
- CRM sends data to adf-data-prod.
- Web shop sends data to evhns-data-prod.
- evhns-data-prod sends data to bronze.
- dbw-data-prod connects to stdatalakeprod (Management: jobs).

Walkthrough
1. One subscription: A resource group per stage, the lake in the middle; the warehouse and Power BI are services.
2. Ingest: Data Factory copies batch sources into bronze; web shop events stream in through Event Hubs.
3. Refine: Databricks jobs clean bronze into silver and model silver into gold, governed by Unity Catalog.
4. Serve: Power BI reports on the Fabric capacity query gold through a serverless SQL warehouse (DirectQuery).

Key
- Solid violet line with ticks: Data flow
- Dotted line with ticks: Management
