Web shop on AWS, per environment

AWS and Google Cloud diagram: Development, without the storefront. 7 elements in 5 groups, with 6 connections.

Groups and elements
- Users
- eu-west-1 (Region)
  - vpc-shop (VPC · 10.20.0.0/16)
    - Internet gateway
    - Load balancer (ALB · public subnets)
    - eu-west-1a (Availability zone)
      - Private subnet
        - Orders API (ECS service · .NET 9): Runs Orders API (shop.api): Places orders and charges cards
      - Isolated subnet
        - Orders DB (RDS database · PostgreSQL 16): Runs Orders DB (shop.db): Orders and customers
  - order-events (SQS queue): Runs order-events (shop.bus): One message for every placed order
  - Mailer (Lambda function · .NET 9): Runs Mailer (shop.worker): Sends receipts for placed orders

Connections
- Users send traffic to Internet gateway over HTTPS.
- Internet gateway sends traffic to Load balancer.
- Load balancer connects to Orders API (Private network).
- Orders API connects to Orders DB (Reads and writes [SQL]) and connects to order-events (OrderPlaced).
- order-events connects to Mailer (OrderPlaced).

Key
- Solid line: Connection
- Solid sky line with ticks: Public traffic
- Dashed teal line: Private network
