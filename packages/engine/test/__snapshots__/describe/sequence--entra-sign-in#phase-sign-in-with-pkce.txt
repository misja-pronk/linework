Sign in with Entra ID

Sequence diagram: Sign in with PKCE and Conditional Access. 3 participants and 8 messages.

Participants
- Employee
- Orders portal (SPA in the browser)
- Microsoft Entra ID (Identity provider)

Message flow
In order, top to bottom.
- 1. Employee calls Orders portal: Open the portal.
- 2. Orders portal does: Make code_verifier and challenge.
- 3. Orders portal calls Microsoft Entra ID: /authorize: scope, code_challenge.
- 4. Employee calls Microsoft Entra ID: Sign in with password.
- 5. Microsoft Entra ID does: Evaluate Conditional Access.
- Optional: Policy requires MFA
  - 6. Microsoft Entra ID calls Employee: Approve in Authenticator (number match).
  - 7. Employee calls Microsoft Entra ID: Approved.
- 8. Microsoft Entra ID replies to Orders portal: Redirect to the portal with code and state.

Key
- Arrow with a filled head: Call
- Dashed arrow: Reply
