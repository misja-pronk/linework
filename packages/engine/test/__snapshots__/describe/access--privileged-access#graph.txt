Walkthrough
1. Three tiers: Tier 0 controls the tenant, Tier 1 manages services such as security and devices, Tier 2 supports users.
2. Break-glass: Two cloud-only accounts hold Global Administrator permanently, for when sign-in or PIM fails. Excluded from Conditional Access, FIDO2 keys in a safe, and an alert on every sign-in.
  - Break-glass accounts: Alert on every sign-in
3. Admins sign in safely: One Conditional Access policy covers every admin group. It requires a privileged access workstation and a phishing-resistant method, and leaves out the break-glass accounts.
4. No standing Tier 0: Tier 0 admins use a separate admin account. Global Administrator is eligible only, for two hours at most, and a second Tier 0 admin approves each activation.
5. Tier 1, just in time: Security and endpoint admins activate their own role for a task, with MFA and a reason, for at most eight hours.
6. Tier 2, scoped: The Dutch service desk resets passwords only for the users in its administrative unit, and can never touch an admin account.
