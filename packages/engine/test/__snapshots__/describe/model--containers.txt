Web shop — containers

Architecture diagram. 8 elements in 1 group, with 7 connections.

Groups and elements
- Customer (User): Buys things in the web shop
- Web shop (System): Sells products online and handles orders
  - Storefront (React)
  - Orders API (.NET 9)
  - Orders DB (PostgreSQL)
  - order-events (Service Bus)
  - Mailer (.NET 9)
- Stripe (Payments)
- SendGrid (Email)

Connections
- Customer connects to Storefront (Browses and orders).
- Storefront calls Orders API (REST).
- Orders API sends data to Orders DB (SQL), sends OrderPlaced to order-events and calls Stripe (Charges cards).
- order-events sends messages to Mailer.
- Mailer connects to SendGrid (Sends receipts).

Key
- Solid line: Connection
- Solid blue line with beads: Request
- Dashed violet line: Async message
- Solid teal line with ticks: Data flow
