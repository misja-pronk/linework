Web shop landscape

Architecture diagram: Who uses the shop and what it depends on. 4 elements, with 3 connections.

Elements
- Customer (User): Buys things in the web shop
- Web shop (System): Sells products online and handles orders
- SendGrid (Email)
- Stripe (Payments)

Connections
- Customer connects to Web shop (Browses and orders).
- Web shop calls SendGrid (Sends receipts) and calls Stripe (Charges cards).

Key
- Solid line with ticks: Connection
- Solid blue line: Request
