Web shop threat model — threats

Architecture, threat table: Threat table. A table of 7 rows by 5 columns.

By row (ID)
Columns: Element or flow, STRIDE, Threat, Mitigation and Status.
- T1: Element or flow Storefront → API gateway; STRIDE Spoofing; Threat Stolen access token replayed from another device; Mitigation Short-lived tokens bound to the client (DPoP); Status Open
- T2: Element or flow Storefront → API gateway; STRIDE Denial of service; Threat Checkout flooded by bots; Mitigation Rate limits per client at the gateway; Status Mitigated
- T3: Element or flow Shop admin → Back office; STRIDE Spoofing, Elevation of privilege; Threat Admin login phished; Mitigation SSO with phishing-resistant MFA (FIDO2); Status Open
- T4: Element or flow Orders service → Orders DB; STRIDE Tampering; Threat SQL injection through order notes; Mitigation Parameterised queries only; Status Mitigated
- T5: Element or flow Orders service → Stripe; STRIDE Repudiation; Threat Customer disputes a charge nobody can trace; Mitigation Signed audit log of every charge request; Status Accepted
- T6: Element or flow Orders service; STRIDE Elevation of privilege; Threat Order ids guessed to read other orders (IDOR); Mitigation Check ownership on every read; Status Open
- T7: Element or flow Orders DB; STRIDE Information disclosure; Threat Backups copied out of the data zone; Mitigation Encrypted backups, keys in KMS; Status Transferred

Threats
- T1 on Storefront → API gateway: Stolen access token replayed from another device (Spoofing). Status open; mitigation: short-lived tokens bound to the client (DPoP).
- T2 on Storefront → API gateway: Checkout flooded by bots (Denial of service). Status mitigated; mitigation: rate limits per client at the gateway.
- T3 on Shop admin → Back office: Admin login phished (Spoofing, Elevation of privilege). Status open; mitigation: SSO with phishing-resistant MFA (FIDO2).
- T4 on Orders service → Orders DB: SQL injection through order notes (Tampering). Status mitigated; mitigation: parameterised queries only.
- T5 on Orders service → Stripe: Customer disputes a charge nobody can trace (Repudiation). Status accepted; mitigation: signed audit log of every charge request.
- T6 on Orders service: Order ids guessed to read other orders (IDOR) (Elevation of privilege). Status open; mitigation: check ownership on every read.
- T7 on Orders DB: Backups copied out of the data zone (Information disclosure). Status transferred; mitigation: encrypted backups, keys in KMS.
