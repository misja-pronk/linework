Order system modernisation

Architecture diagram: The monolith is strangled one capability at a time. 6 elements in 1 group, with 7 connections.

Groups and elements
- Web shop (Web app)
- API gateway (all traffic) (API gateway)
- New platform (System)
  - Payments (Service)
  - Orders (Service)
  - Order events (Queue)
  - Orders DB (Database)

Connections
- Web shop connects to API gateway (all traffic) over HTTPS.
- API gateway (all traffic) connects to Payments and connects to Orders.
- Payments connects to Order events and connects to Orders DB.
- Orders connects to Order events and connects to Orders DB.
