Offices and the hub

Azure infrastructure diagram: Northwind lakehouse · users reach the workspaces over ExpressRoute and the hub's private endpoints. 11 elements in 4 groups, with 7 connections.

Groups and elements
- Northwind on-premises (10.10.0.0/16)
  - Data engineer (Browser)
  - Office DNS (Conditional forwarders)
- vnet-hub-weu (10.0.0.0/22 · sub-connectivity)
  - ergw-hub-weu (ExpressRoute gateway · GatewaySubnet)
  - pep-dbw-lakehouse-prod-ui (databricks_ui_api · snet-pep)
  - pep-dbw-webauth-weu (browser_authentication · snet-pep)
  - dnspr-hub-weu (Resolver inbound · 10.0.1.100)
- Databricks control plane (West Europe)
  - dbw-lakehouse-prod (Web app · REST API · SCC relay)
  - dbw-webauth-weu (Browser sign-in only): Holds the region's browser_authentication endpoint; delete lock
- Private DNS zones (Linked to vnet-hub-weu)
  - privatelink.azuredatabricks.net (Workspace and pl-auth records)
  - privatelink.dfs.core.windows.net (dfs endpoints)
  - privatelink.blob.core.windows.net (blob endpoints)

Connections
- Data engineer connects to ergw-hub-weu (Private network: HTTPS).
- ergw-hub-weu connects to pep-dbw-lakehouse-prod-ui (Private network) and connects to pep-dbw-webauth-weu (Private network: SSO).
- pep-dbw-lakehouse-prod-ui connects to dbw-lakehouse-prod (Private network: front-end).
- pep-dbw-webauth-weu connects to dbw-webauth-weu (Private network: browser sign-in).
- Office DNS connects to dnspr-hub-weu (Private network: DNS · over ExpressRoute).
- dnspr-hub-weu connects to privatelink.azuredatabricks.net (Resolves).

Walkthrough
1. Offices and the hub: ExpressRoute ends in the hub, which holds the DNS resolver and each workspace's front-end endpoint.
2. Finding the workspace: Office DNS forwards *.azuredatabricks.net to the resolver, which answers from the zones linked to the hub.
3. A user's browser: The workspace URL resolves to the front-end endpoint; test and dev have one each in snet-pep.
4. Signing in: After Entra ID the browser returns through the region's one browser_authentication endpoint.
