- ncc-lakehouse-prod connects to stordersprod (Private network: serverless).

Walkthrough
1. Production: A VNet-injected workspace with no public access; the hub holds the front-end endpoints and the firewall.
2. A user's browser: The workspace URL resolves in privatelink.azuredatabricks.net to the front-end endpoint in the hub.
3. Signing in: After Entra ID the browser returns through the region's one browser_authentication endpoint.
4. A cluster: Clusters dial out to the SCC relay and the REST API through the back-end endpoint; no inbound ports.
5. Reading data: Clusters reach each domain's account through its own dfs endpoint, named in privatelink.dfs.core.windows.net.
6. Serverless: SQL warehouses and serverless jobs reach the same accounts through the NCC's private endpoints.
7. Everything else: rt-lakehouse-prod sends 0.0.0.0/0 to afw-hub, so package mirrors and the rest leave through the firewall.
