Checkout

Sequence, confirmation: Confirmation. 6 participants and 10 messages.

Participants
- Shopper
- Shop system
  - Storefront (Web app)
  - Orders API (Service)
  - Orders DB (Database)
  - order-events (Event stream)
- Stripe (Payments)

Message flow
In order, top to bottom.
- Alternative: Payment succeeded
  - 10. Stripe sends to Orders API: webhook payment_intent.succeeded.
  - 11. Orders API calls Orders DB: UPDATE order SET status = paid.
  - 12. Orders DB replies to Orders API: ok.
  - 13. Orders API sends to order-events: OrderPaid.
- Else: Card declined
  - 14. Stripe sends to Orders API: webhook payment_intent.payment_failed.
  - 15. Orders API calls Orders DB: UPDATE order SET status = failed.
  - 16. Orders DB replies to Orders API: ok.
- 17. Storefront calls Orders API: Poll GET /orders/{id}.
- 18. Orders API replies to Storefront: status: paid or failed.
- 19. Storefront replies to Shopper: Confirmation, or try another card.

Key
- Arrow with a filled head: Call
- Dashed arrow: Reply
- Arrow with an open head: Async message
