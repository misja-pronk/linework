Connections

- Webshop events connects to Orders.

Walkthrough
1. One product, one team: Orders belongs to the order management team. They run it, version it and answer for it.
2. Input ports: Changes come from the ERP through change data capture, webshop events as a stream. Nobody else reads these systems.
3. The contract: The orders table promises a schema, freshness within 15 minutes and checks that run on every load. A breaking change is a new major version.
4. Lineage onwards: Revenue, the demand forecast, the sales dashboard and the loyalty app depend on it. They are told before the contract changes.
