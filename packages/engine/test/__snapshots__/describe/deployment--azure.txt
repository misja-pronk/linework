Web shop on Azure

Azure infrastructure diagram: Every environment at once. 9 elements in 5 groups, with 9 connections.

Groups and elements
- Users
- Front Door and WAF (Front Door): tagged prod
- Shop (Subscription)
  - rg-shop (Resource group)
    - Storefront (Static Web App · React): Runs Storefront (shop.web): Shows the catalogue and takes orders
    - vnet-shop (Virtual network)
      - snet-apps (Subnet)
        - Orders API (Container App · .NET 9): Runs Orders API (shop.api): Places orders and charges cards
      - snet-data (Subnet)
        - Orders DB (PostgreSQL 16): Runs Orders DB (shop.db): Orders and customers
        - Read replica (PostgreSQL): tagged prod
    - kv-shop (Key Vault): tagged prod, test
    - order-events (Service Bus): Runs order-events (shop.bus): One message for every placed order
    - Mailer (Function App · .NET 9): Runs Mailer (shop.worker): Sends receipts for placed orders

Connections
- Users send traffic to Front Door and WAF over HTTPS and send traffic to Storefront over HTTPS [tagged test, dev].
- Front Door and WAF sends traffic to Storefront.
- Storefront connects to Orders API (Calls [REST]).
- Orders API connects to Orders DB (Private network: SQL), signs in with kv-shop and connects to order-events (OrderPlaced).
- Orders DB sends data to Read replica (replication).
- order-events connects to Mailer (OrderPlaced).

Key
- Solid line: Connection
- Solid sky line with beads: Public traffic
- Dashed teal line: Private network
- Solid violet line with ticks: Data flow
- Amber badge: Identity badge
- Tag prod: Only in the environments named; unmarked: in all (prod, test, dev)
