Kubernetes diagram: One namespace, from ingress to Postgres. 11 elements in 2 groups, with 20 connections.

- Customers (Users)
- prod-eu-1 (Cluster)

    - web (Service · :80)
    - api (Service · :80→8080)
    - web (Deployment · ×2)
    - api (Deployment)

    - invoice-run (CronJob · 0 3 * * *)
- Stripe (External)

Connections
- Customers send traffic to shop (Ingress) over HTTPS.
- shop (Ingress) sends traffic to web (Service) (/), sends traffic to api (Service) (/api) and mounts shop-tls.
- web (Service) sends traffic to web (Deployment).
- api (Service) sends traffic to api (Deployment).
- api (Deployment) sends traffic to postgres (SQL), sends traffic to redis, sends traffic to Stripe (payments), mounts api-config, mounts db-credentials, signs in with shop-api and is scaled by HPA ×3–12.
- postgres mounts data · 50Gi and mounts db-credentials.
- redis mounts data · 5Gi.
- order-worker sends traffic to postgres and mounts db-credentials.
- invoice-run sends traffic to postgres and mounts db-credentials.

Key
- Solid blue line: Traffic
- Badge: Mounted config, secret or volume
- Amber badge: Identity badge
- Green badge: Scaled by an autoscaler
