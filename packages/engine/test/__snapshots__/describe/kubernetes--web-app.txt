- api (Service) sends traffic to api (Deployment).
- api (Deployment) sends traffic to postgres (Service) (SQL), sends traffic to redis, sends traffic to Stripe (payments), mounts api-config, mounts db-credentials, signs in with shop-api and is scaled by HPA ×3–12.
