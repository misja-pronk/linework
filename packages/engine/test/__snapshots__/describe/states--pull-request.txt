Pull request lifecycle

States diagram: What a pull request can become, and what moves it there. 10 states in 1 group, with 13 transitions.

Groups and elements
- Start
- Draft
- In review
  - Start of In review
  - Awaiting review: entry / request reviewers
  - Changes requested
  - Approved
- Closed
- Not yet visible in the review queue (note)
- Merged: entry / delete the branch
- End

Main path
1. Start
2. Draft: opened
3. Awaiting review: ready for review
4. Closed: closed without merging

Transitions
- Start moves to Draft on opened.
- Draft moves to In review on ready for review.
- In review moves to Draft on converted to draft and moves to Closed on closed without merging.
- Closed moves to In review on reopened.
- Not yet visible in the review queue is a note on Draft.
- Start of In review moves to Awaiting review.
- Awaiting review moves to Changes requested on review [needs work] and moves to Approved on review [looks good].
- Changes requested moves to Awaiting review on new commits pushed.
- Approved moves to Awaiting review on new commits pushed and moves to Merged on merge [checks green].
- Merged moves to End.
